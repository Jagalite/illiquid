# Retained Linux evidence

These are the raw measurements, process logs, test results and receipts from the six-round Swift 6.3.2 study described in the research report. The full output was independently verified before this compact snapshot was copied. It excludes generated build directories and executable binaries; their hashes and exact source identities remain in `manifest.json`. Run the documented runner into a fresh directory to recreate the complete artifact set accepted by `verify.py`.

Timing source: main `8c3cc3d4008d5d1b8d436bcf2d51d891382b6548` reconstructed by the pinned function fixture versus the ten-line endpoint shortcut. No decoder, SwiftUI window, native drawing, or whole-player resource measurements are included. Linux Path uses the documented point collector. Source/binary hashes, command output and complete AB/BA pairs were checked; 156 observations across 13 scenarios and six rounds.
