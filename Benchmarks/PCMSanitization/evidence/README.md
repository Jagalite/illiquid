The unused XCTest process is disabled in the standalone package with SwiftPM's
`--disable-xctest --enable-swift-testing` options. That package contains only
Swift Testing tests. The successful repeat did not set `ASAN_OPTIONS` or disable
leak checking. The unsuccessful result is preserved as an unsuccessful result,
not counted among the passing qualification runs.

Formal performance results use the final production source and frozen runner.
The final test refresh only added explicit ignored-result assignments to two
`withExtendedLifetime` calls; the refreshed normal and instrumented receipts
match the checked-in test file. Each phase retains exact generated production
source, test source when applicable, and a runner snapshot when available.
Early exploratory runs predate automatic runner snapshots; their reports retain
the compiler commands, source/harness/runner hashes, and input/output checks.

The candidate was measured before the git commit, so its recorded git HEAD is
the baseline and its worktree status shows edits. The complete candidate source
and extracted declaration hashes identify the actual tested implementation.
These hashes, rather than the worktree's then-current HEAD alone, should be
used when checking source identity.

## Exact output receipts

`verification-records.json.xz` contains the complete JSON output of the formal
preflight. Baseline and candidate generated byte-identical JSON records, so one
copy represents both. Both native macOS cohorts produced the identical body;
their qualification receipts point to the same file. It includes original and sanitized bytes, counts,
workload metadata, and all 880 fixture records (including repeated control
families). The preflight compares 28,904,816 sanitized output bytes.

This file is the original JSON body compressed with Python `lzma` (XZ, preset
6), replacing two larger gzip copies without changing the decompressed bytes.
`verification-manifest.json` provides per-fixture SHA-256 values and the whole
receipt's compressed and uncompressed hashes. To read and check it:

```python
import hashlib
import json
import lzma
from pathlib import Path

root = Path("Benchmarks/PCMSanitization/evidence")
manifest = json.loads((root / "verification-manifest.json").read_text())
body = lzma.decompress((root / "verification-records.json.xz").read_bytes())
assert hashlib.sha256(body).hexdigest() == manifest["verification"]["output_sha256"]
records = json.loads(body)
assert len(records) == 55
```

`SHA256SUMS` checks the retained evidence files. Executables, objects, modules,
compiler caches, and package build trees are omitted. Build receipts retain
the executable hashes and exact compiler commands. This directory documents
component measurements and test results; it does not contain a player CPU or
energy profile.
